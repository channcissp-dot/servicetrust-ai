# ServiceTrust AI - AI-Powered Non-Human Identity Governance
### Product Case Study by Channakeswara Vuppalamarthi | AI Product Management Portfolio

**Problem:** 5,000-7,000 service accounts in Insurance enterprise (99% Entra ID), 50% high-risk Interactive/Shadow/RPA, 14-day manual provisioning, NYDFS fine risk $2-10M.

**Solution:** AI Product with 5 Agents - Discovery (20+ sources incl CyberArk), Risk Scoring, Owner Prediction, Anomaly Detection, GenAI Copilot.

**Stack:** Azure Entra ID, AD, CyberArk, SailPoint, ServiceNow, Sentinel, ADX, Azure OpenAI

## Quick Start (Vibe Code)
1. Clone repo
2. pip install -r requirements.txt
3. uvicorn src.api.main:app --reload
4. Open http://localhost:8000/docs
